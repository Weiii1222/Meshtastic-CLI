# Wio Tracker L2 产品需求规范

> 版本：v1.0 | 日期：2026-08-21 | 固件：Meshtastic MUI
> 来源：基于测试用例覆盖功能点反向整理

---

## 一、产品概述

Wio Tracker L2 是一款便携式 LoRa Mesh 自组网通信终端，基于 ESP32-S3 + SX1262 LoRa 芯片，搭载 3.2 英寸 IPS 触摸屏、GPS 定位、WiFi/BLE 无线通信，运行 Meshtastic 开源固件。

**核心使用场景：** 户外无手机信号区域的文字通信、位置共享、Mesh 组网。

---

## 二、固件烧录

| 需求项 | 说明 |
|------|------|
| Web Flasher 网页烧录 | 通过浏览器访问 flasher.meshtastic.org，USB 连接设备后在线烧录固件 |
| Flash Download Tool 烧录 | 乐鑫官方工具，选择 ESP32-S3 芯片，加载固件 bin 文件烧录至地址 0x0 |
| 全片擦除并重新烧录 | 先 ERASE 擦除全片 Flash，再烧录固件，所有配置恢复出厂默认 |

## 五、节点列表

| 需求项 | 说明 |
|------|------|
| 节点列表显示 | 显示扫描到的所有周边 Meshtastic 设备 |

| 条件 | 作用 |

| Position | 显示/隐藏有位置信息的节点 |
| Active Chat | 显示/隐藏有活跃聊天的节点 |
| Telemetry | 显示/隐藏有遥测数据的节点 |
| IAQ | 显示/隐藏有空气质量数据的节点 |
| Name | 通过名称关键词检索匹配目标节点 |

### 5.2 Highlight 高亮

| 条件 | 作用 |

## 六、频道

## 十一、模式切换

| 模式 | 进入方式 | 说明 |
|------|------|------|
| MUI | 默认模式 | 触屏图形界面，6 个主界面 |
| BaseUI | Settings → Reboot/ShutDown → 长按蓝牙 icon → Reboot into BaseUI | 基础文本界面，配置与 MUI 同步。支持 EU_868 / 915MHz 通信 |
| Programming Mode | Settings → Reboot/ShutDown → 点击蓝牙 icon | 维护模式，手机 APP 可通过蓝牙连接进行固件升级等操作 |

### BaseUI 需求

| 需求项 | 说明 |
|------|------|
| 通信 | 支持 EU_868 和 915MHz 频段下正常收发消息 |
| 稳定性 | 长时间使用不出现花屏、卡死、自动重启 |
| 切换回 MUI | System Action → Reboot/Shutdown → Switch to MUI → 自动重启切回 |
