# Wio Tracker L2 固件缺陷报告

> 固件版本：2.7.25 | 发现阶段：DVT | 测试设备：Wio Tracker L2 标准版 | 测试日期：2026-08-13

---

## Bug 1：WAKE键偶发无法唤醒设备

| 字段 | 内容 |
|------|------|
| 缺陷名称 | WAKE键偶发无法唤醒设备 |
| 问题分类 | 嵌入式软件 |
| 出现版本 | 2.7.25 |
| 发现阶段 | DVT |
| 严重程度 | 重要 |
| 优先级 | P0 |
| 关联项目 | Wio Tracker L2 |
| DPM | 覃青林 |
| 缺陷负责人 | 唐鹏飞 |

**缺陷描述：**

设备休眠超过一段时间后，按下WAKE键无法唤醒设备，屏幕保持黑屏，只能通过按RST键重启恢复。

**操作步骤：**

1. 设备开机进入MUI界面
2. 按下WAKE键使设备进入休眠
3. 等待较长时间（约10分钟以上）
4. 按下WAKE键尝试唤醒
5. 设备无响应，屏幕保持黑屏

**预期结果：** 按下WAKE键后屏幕立刻亮起，回到休眠前页面。

## Bug 3：消息提醒Banner和Sound不同步

| 字段 | 内容 |
|------|------|
| 缺陷名称 | 消息提醒Banner和Sound不同步 |
| 问题分类 | 嵌入式软件 |
| 出现版本 | 2.7.25 |
| 发现阶段 | DVT |
| 严重程度 | 一般 |
| 优先级 | P1 |
| 关联项目 | Wio Tracker L2 |
| DPM | 覃青林 |
| 缺陷负责人 | 唐鹏飞 |

**缺陷描述：**

消息提醒模式设置为Banner & Sound后，收到消息时偶发弹窗通知和声音提醒不同步：要么只有声音没有弹窗横幅，要么只有弹窗横幅没有提示音。

**操作步骤：**

1. 设备开机进入MUI主界面
2. 单击消息提醒区域，切换至Banner & Sound模式
3. 从另一台设备发送消息
4. 观察本设备是否有横幅通知和铃声

**预期结果：** 收到消息时同时弹出横幅通知并同步播放提示铃声。

## Bug 4：Channel频道筛选不生效

| 字段 | 内容 |
|------|------|
| 缺陷名称 | Channel频道筛选仅显示本机，不显示同频道其他节点 |
| 问题分类 | 嵌入式软件 |
| 出现版本 | 2.7.25 |
| 发现阶段 | DVT |
| 严重程度 | 重要 |
| 优先级 | P0 |
| 关联项目 | Wio Tracker L2 |
| DPM | 覃青林 |
| 缺陷负责人 | 唐鹏飞 |

**缺陷描述：**

在节点列表中有多台同频道设备时，开启Channel频道筛选功能后，节点列表仅显示当前本机，同频道其他节点没有被筛选展示出来。

**操作步骤：**

1. 确保节点列表中有多台同频道在线设备

3. 选择Filter
4. 开启Channel筛选条件
5. 观察节点列表

**预期结果：** 开启频道筛选后，节点列表展示当前频道所有节点；关闭筛选后恢复显示全部节点。

## Bug 7：锁屏后默认密码000000无法解锁

| 字段 | 内容 |
|------|------|
| 缺陷名称 | 设置屏幕锁后默认密码000000无法解锁设备 |
| 问题分类 | 嵌入式软件 |
| 出现版本 | 2.7.25 |
| 发现阶段 | DVT |
| 严重程度 | 严重 |
| 优先级 | P0 |
| 关联项目 | Wio Tracker L2 |
| DPM | 覃青林 |
| 缺陷负责人 | 唐鹏飞 |

**缺陷描述：**

在Settings > Lock页面开启屏幕锁并自定义PIN码后，锁屏界面使用默认密码000000无法解锁设备，存在设备被锁死无法使用的风险。

**操作步骤：**

1. 设备开机进入Settings > Lock
2. 开启屏幕锁
3. 设置自定义PIN码（非000000）
4. 等待锁屏
5. 在锁屏界面输入000000尝试解锁

**预期结果：** 默认密码000000在任何自定义PIN码场景下都可解锁设备。

## Bug 9：Signal Scanner退出后节点列表被异常筛选

| 字段 | 内容 |
|------|------|
| 缺陷名称 | 使用Signal Scanner后节点列表被异常筛选且无法恢复 |
| 问题分类 | 嵌入式软件 |
| 出现版本 | 2.7.25 |
| 发现阶段 | DVT |
| 严重程度 | 一般 |
| 优先级 | P1 |
| 关联项目 | Wio Tracker L2 |
| DPM | 覃青林 |
| 缺陷负责人 | 唐鹏飞 |

**缺陷描述：**

使用Tools > Signal Scanner功能完成扫描并返回节点列表后，用户未开启任何筛选规则的前提下，节点列表自动被异常筛选，且无法恢复显示全部节点。

**操作步骤：**

1. 设备开机进入节点列表，确认有多个节点可见
2. 进入Settings > Tools > Signal Scanner
3. 选择节点并点击Start
4. 完成扫描后返回节点列表
5. 观察节点列表显示

**预期结果：** 退出Signal Scanner后，节点列表维持扫描前的状态，显示全部节点，不受异常修改。

## 严重程度参考

| 严重程度 | 定义 |
|------|------|
| **严重** | 导致设备无法使用、锁死、数据丢失 |
| **重要** | 核心功能失效，影响主要使用场景 |
| **一般** | 部分功能异常，有替代方案 |
| **轻微** | UI显示问题，不影响功能 |
